#💡 Советы по выбору режима:
Применение
Рекомендуемые режимы
Плавное изменение яркости/громкости LINEAR, SINUSOIDAL_INOUT, QUADRATIC_INOUT
Анимация появления/исчезновения UI QUADRATIC_OUT, CUBIC_OUT, SINUSOIDAL_OUT
Эффекты "пружинного" интерфейса ELASTIC_OUT, BACK_OUT
Игровые анимации (прыжки, удары) BOUNCE_OUT, ELASTIC_INOUT, BACK_INOUT
Технические переходы (PWM, серво) LINEAR, QUADRATIC_INOUT (избегать резких скачков)
Драматичные акценты EXPONENTIAL_IN, QUINTIC_OUT, CIRCULAR_INOUT
